Полезная информация для работы с эксель файлами:
Существует множество способов прочитать и преобразовать XLSX‑файл в удобный для обработки в Python вид. Помимо наиболее популярных pandas.read_excel и openpyxl, можно использовать библиотеки xlrd, xlwt, xlutils, pyexcel, pyxlsb, odfpy, COM‑автоматизацию через win32com, конвертацию через csvkit или веб‑сервисы. Ниже приведены 10 различных подходов, каждый со своими плюсами и минусами.
1. pandas.read_excel

Использует движок openpyxl или xlrd под капотом и сразу возвращает DataFrame.

import pandas as pd
df = pd.read_excel("file.xlsx", sheet_name=0)
records = df.to_dict(orient="records")

    Плюсы: очень удобно для аналитики, мощные средства фильтрации и преобразования.

    Минусы: тяжёлая зависимость (~10 MB) .

2. openpyxl

Чтение через чистый Python, подходит для доступа к формату и стилям.

from openpyxl import load_workbook
wb = load_workbook("file.xlsx", read_only=True)
ws = wb.active
rows = list(ws.values)
headers, *data = rows
records = [dict(zip(headers, r)) for r in data]

    Плюсы: поддерживает формулы, стили, комментарии.

    Минусы: чуть медленнее, больше кода .

3. xlrd

Лёгкая библиотека для чтения старых XLS и ранних XLSX (до версии 2.0).

import xlrd
book = xlrd.open_workbook("file.xlsx")
sheet = book.sheet_by_index(0)
headers = sheet.row_values(0)
data = [dict(zip(headers, sheet.row_values(i))) for i in range(1, sheet.nrows)]

    Плюсы: быстрая для чтения.

    Минусы: не поддерживает современные XLSX с новым форматом после xlrd 2.0 .

4. pyexcel

Универсальный API для разных форматов: CSV, XLS, XLSX, ODS.

import pyexcel as pe
sheet = pe.get_sheet(file_name="file.xlsx")
records = sheet.to_records()

    Плюсы: единый интерфейс, легко расширяем.

    Минусы: менее производительна на больших файлах .

5. xlwings

Использует Excel через COM/AppleScript, подходит для сложных макросов.

import xlwings as xw
wb = xw.Book("file.xlsx")
sheet = wb.sheets[0]
data = sheet.range("A1").options(expand="table").value

    Плюсы: полностью управляет Excel, можно запускать VBA.

    Минусы: требует установленного Excel, работает только на Windows/Mac .

6. pyxlsb

Чтение бинарных XLSB (Excel Binary Workbook).

from pyxlsb import open_workbook
with open_workbook("file.xlsb") as wb:
    with wb.get_sheet(1) as sheet:
        data = [row for row in sheet.rows()]

    Плюсы: поддерживает формат .xlsb, быстрее чтения.

    Минусы: узкий формат, не XLSX .

7. odfpy

Чтение OpenDocument Spreadsheet (ODS) как альтернативы XLSX.

from odf.opendocument import load
from odf.table import Table, TableRow, TableCell
doc = load("file.ods")
sheet = doc.spreadsheet.getElementsByType(Table)[0]
# парсинг строк и ячеек вручную

    Плюсы: нативно для ODS.

    Минусы: громоздко, слабее документирован .

8. csvkit (in2csv)

CLI‑утилита, конвертирующая XLSX → CSV, далее читать стандартным модулем csv.

in2csv file.xlsx > file.csv

import csv
with open("file.csv") as f:
    reader = csv.DictReader(f)
    data = list(reader)

    Плюсы: разделение на этапы, подходит для пайплайнов.

    Минусы: требует внешний инструмент .

9. REST API (Google Sheets)

Загрузить в Google Sheets и читать через API как JSON.

import requests
url = "https://sheets.googleapis.com/v4/spreadsheets/.../values/Sheet1"
resp = requests.get(url, params={"key": API_KEY})
data = resp.json()["values"]

    Плюсы: нет Python‑парсинга, всегда свежие данные.

    Минусы: требует загрузки в Google, настройку API .

10. WebAssembly (ExcelJS + Pyodide)

В браузере распарсить XLSX через JS-библиотеку, передать JSON на сервер.

import ExcelJS from 'exceljs';
const workbook = new ExcelJS.Workbook();
await workbook.xlsx.load(file);
const sheet = workbook.getWorksheet(1);
const data = sheet.getSheetValues();
await fetch('/upload', { method:'POST', body: JSON.stringify(data) });

    Плюсы: разгрузка сервера, делегирование клиенту.

    Минусы: сложность на клиенте, большие файлы медленно .

Выбор решения зависит от размеров файла, требований к зависимостям и платформенным ограничениям.
